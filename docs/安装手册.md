# 安装手册

要求本地已安装 [Node.js](https://nodejs.org/)（建议 20+）。装好后在侧栏「设置」里配置模型 API Key（自带密钥，仅存本机）；默认地址 `http://127.0.0.1:4321/`。

## 方式一：本地服务（推荐）

### 1. 安装

```bash
npx ai-testbench
```

执行后会安装全局短命令 **`tbench`**（npm 包名为 `ai-testbench`）。

### 2. 初始化数据空间

首次必做；可再次执行以更换数据空间：

```bash
tbench init
```

按序号选择：

```text
选择数据目录（其下直接放置「公共空间」与其它空间；知识库 / 用例 / 提示词 / 记忆等写入其中）：
  1) 打开系统文件夹选择器
  2) 当前目录（当前终端所在位置）
  3) 自定义路径（手输）
请输入 1 / 2 / 3（默认 1）：
```

选项 `2` 的「当前目录」指执行命令时终端所在的工作目录（不是系统根 `/`，也不是固定的项目仓库根）。

选择结果记在本机（`tbench config` 可查看配置文件地址），供后续 `tbench web` 使用。若数据空间被移动/重命名/删除，请重新 `tbench init` 初始化或选择已有数据空间。

### 3. 常用命令

```bash
tbench init           # 选择并记住数据空间
tbench web            # 启动本地 Web 服务
tbench stop           # 停止服务
tbench restart        # 重启服务
tbench status         # 运行状态、端口、数据空间
tbench open           # 在浏览器中打开工作台
tbench path           # 显示当前数据空间路径
tbench config         # 显示配置文件地址
tbench logs           # 查看服务日志
tbench doctor         # 检查运行环境与配置是否正常
tbench help           # 显示操作命令列表
tbench version        # 显示当前版本号
tbench list           # 显示可安装的版本列表
tbench install        # 安装/更新到最新版本
tbench install 0.1.x  # 安装/更新到指定版本
tbench uninstall      # 卸载本机 tbench 命令（保留数据空间）
tbench wipe           # 删除当前数据空间（需确认；不可恢复）
tbench ask            # 进阶：无界面单轮问答，tbench ask <提示词>
tbench rpc            # 进阶：以 stdio JSON-RPC 暴露本地问答能力
tbench acp            # 进阶：以 ACP 子集供外部编排驱动无 UI Agent
```

### 4. 打开工作台

浏览器打开终端提示的地址（或 `tbench status` / `tbench open`），在侧栏「设置」配置模型即可。

## 方式二：源码启动

适合改代码或二次开发。

### 1. 克隆仓库

```bash
git clone https://github.com/yychuiyan/ai-testbench.git
cd ai-testbench
```

### 2. 开发模式

热更新，含本地落盘 API：

```bash
pnpm install
pnpm dev
```

### 3. 预览静态页

需先打包；无本地落盘：

```bash
pnpm build
pnpm preview
```

更完整的产品用法见 [操作手册](https://testbench.yychuiyan.com/docs/manual/)。
