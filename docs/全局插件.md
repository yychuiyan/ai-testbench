来源：[`src/lib/builtin-plugin-catalog.ts`](../src/lib/builtin-plugin-catalog.ts) 的 `GLOBAL_PLUGIN_CATALOG`（决策清单「做」）。

- **策略**：平台默认能力目录；插件页「全局」Tab 展示，多数无用户开关。
- **实现层**：本文件为规格与对照；**不等于**已全部实现。与扩展/`tb-*` 有重叠的在「TestBench 映射」注明。
- **扩展插件**（可开关，另见 `plugins.ts`）：`caseGen` / `promptGen` / `knowledgeGen` / `knowledge` / `memory` — 对应 `tb-kb`、`tb-memory`、`tb-project-docs` 等，不在本全局清单逐条重复产品开关逻辑。
