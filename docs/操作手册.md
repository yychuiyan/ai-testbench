# 操作手册

本文说明模型配置、工作台用法、内容目录与插件。安装与启动见仓库根目录 [README.md](../README.md)。

## 使用 AI 功能（BYOK）

点击左侧导航底部「设置」→「模型」，填入任意 OpenAI 兼容接口：

| 预设     | Base URL                                            | 模型示例         |
| -------- | --------------------------------------------------- | ---------------- |
| DeepSeek | `https://api.deepseek.com/v1`                       | `deepseek-flash` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus`      |
| OpenAI   | `https://api.openai.com/v1`                         | `gpt-4o-mini`    |
| 自定义   | 任意 OpenAI 兼容端点                                | 任意模型名       |

> 模型名以设置弹窗中自动识别的下拉列表为准（来自端点 `GET /models` 的实时返回）。例如 DeepSeek 的 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07 停用，当前可用型号为 `deepseek-flash`（V4.1 Flash）。

> **安全提示**：Key 仅保存在本机浏览器 localStorage，不会上传任何服务器，也不会进入仓库。请勿在公共电脑上使用；请勿把 Key 写入任何会被提交的文件。

## 我的工作台

侧栏进入「我的工作台」。空会话居中展示品牌与标语「让测试更高效」，并隐藏会话标题与「对话 / 回合 / 记忆」Tab；发出首条消息后顶栏与 Tab 出现。

### 会话与工作区

- 侧栏「新会话」创建空对话；无消息的空会话在切换走时会被丢弃。
- 会话可置顶、重命名、归档、软删除；支持导出会话 JSON。
- 侧栏按工作区文件夹组织会话；输入栏可切换 / 添加本地工作区（需本地文件服务就绪，一般即 `npm run dev` / `npx ai-testbench`）。
- 访问权限：仅可查看 / 工作区内修改 / 完全权限（输入栏内切换）。

### 对话 Tab

- 流式回复；思考与工具步骤可在时间线中展开。
- 输入栏：`+` 打开添加面板；`/` 唤起插件菜单；`@` 引用知识库 / 模板 / 工作区文档。
- 支持添加文件、粘贴图片与本地路径；发送后可查看用量与会话统计。
- 有一体服务时，回合可在服务端继续跑，刷新/切页可重连；手动停止展示「已停止」。

### 回合 Tab

- 按轮次列出用户 / 助手摘要，可展开查看完整正文（不含思考）。
- **从此处继续**：截断到该轮末，切回「对话」，填入「请从第 N 轮继续」并自动发送。待回复或生成中时按钮不可用。

### 记忆 Tab

需开启扩展插件「会话记忆」。见下文「会话记忆」。

### 生成类扩展（用例 / 提示词 / 知识库）

1. 插件库打开对应扩展。
2. 在工作台用 `/` 或添加面板打开配置抽屉，确认后进入（或复用）空会话，标题保持「新对话」直至首次发送。
3. 在主输入框描述素材与要求后发送；类型/分类的删除为行内二次确认（确认 / 取消）。

## 内容目录约定

磁盘为**英文目录**，侧栏/文案为**中文**。文件即数据：放入对应目录并 push，构建后上架。

| 界面       | 磁盘目录        |
| ---------- | --------------- |
| 需求文档库 | `requirements/` |
| 用例管理   | `cases/`        |
| 提示词管理 | `prompts/`      |
| 知识库管理 | `knowledge/`    |
| 测试模板库 | `templates/`    |

```text
templates/
  功能测试用例/  接口测试用例/  性能测试用例/
  功能测试报告/  接口测试报告/  性能测试报告/
knowledge/
  测试规范/  方法论/  环境约定/
```

**模板库**支持：

| 格式             | 行为                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| `.md`            | 在线上架预览 + 下载（须带 frontmatter）                                      |
| `.xlsx` / `.xls` | 按分类上架；构建期读取工作表名与首行表头，列表展示字段摘要；**仅下载**不预览 |
| `.docx` / `.doc` | 按分类上架，**仅下载**（不做在线预览）                                       |

Markdown frontmatter（构建期校验）：

```yaml
---
title: 显示标题 # 必填
category: 功能测试用例 # 必填；模板库六类之一，或知识库：测试规范/方法论/环境约定
description: 一句话描述 # 可选
version: '1.0' # 可选（仅模板库）
---
```

库页支持「在会话中打开」：新建空会话并挂路径卡片（不预填正文）；确认生成类插件时同理。

## 插件（内置，仅开关）

侧栏进入 **我的插件**（子路由可刷新保持）：

- **我的插件**（`/plugins/`）：会话默认 / 全局默认 / 扩展（可开关）；状态存浏览器 localStorage。插件随仓库代码发布，不提供远程安装。
- **插件管理**（`/plugins/manage/`）：顶部输入框回车/发送按诉求推荐；下方「推荐插件」按本项目现状推荐；结果缓存本机。
- 规格目录：[`会话插件.md`](./会话插件.md)、[`全局插件.md`](./全局插件.md)。

| 插件         | 默认 | 说明                                                                                               |
| ------------ | ---- | -------------------------------------------------------------------------------------------------- |
| 生成测试用例 | 开   | 配置类型/模板/提示词后对话生成用例（需本地服务落盘）                                               |
| 生成提示词   | 开   | 配置类型后对话生成提示词并写入 `prompts/`                                                          |
| 生成知识库   | 开   | 配置分类后对话生成规范/方法论等，质检后写入 `knowledge/`（需本地服务）                             |
| 知识库检索   | 开   | AI 工作台输入 `@` 引用 knowledge/、templates/、工作区；模型 `kb_*` 按需读取                        |
| 会话记忆     | 开   | 五轨 md（user/memory/key + project/daily），待确认队列；`.local/memories/`（需本地服务）           |

### 知识库检索（@ 引用）

1. 插件库打开「知识库检索」。
2. 在 AI 工作台输入 `@`（可继续输入关键词过滤），↑↓ 选择，Enter 确认；文档会挂到输入框附件区并随消息发送。
3. 构建期写入文档列表，Pages 线上同样可用（读静态 `/raw/...` 路径）；工作区文件需本地文件服务。

### 会话记忆

1. 插件页打开「会话记忆」；存储：`.local/memories/`（USER / MEMORY / KEY / project / daily + SUGGESTIONS）。
2. 工具：`memory_search` / `memory_read` / `memory_suggest` / `memory_append`。
3. 重要事实经「待确认」采纳后才注入；项目/每日日志可直写；工作台「记忆」Tab 管理。
4. 旧版 `graph.json` 首次启动会尝试迁入 USER/MEMORY。

`.local/` 已加入 `.gitignore`，**不会提交到 Git**。
